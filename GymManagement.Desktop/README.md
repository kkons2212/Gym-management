# GYM HOUSE — WinUI 3 prototype

Desktop UI prototype for the Admin, personal trainer, and member workspaces. All displayed records are sample data; this project does not connect to an API or database.

## Run

From the repository root on Windows:

```powershell
dotnet run --project .\GymManagement.Desktop\GymManagement.Desktop.csproj
```

Use the role selector in the top bar to switch between the three workspaces, then use the left navigation to preview each role's main screens.
