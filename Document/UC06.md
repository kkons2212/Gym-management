| **Use Case ID** | **UC06** |
| :--- | :--- |
| **Tên Use Case** | **Xem báo cáo và thống kê** |
| **Tóm tắt** | Admin xem các báo cáo và số liệu thống kê của phòng gym theo các tiêu chí lọc và khoảng thời gian xác định. |
| **Dòng sự kiện chính** | 1. Admin chọn chức năng "Xem báo cáo và thống kê".<br>2. Hệ thống hiển thị màn hình báo cáo và các tùy chọn lọc dữ liệu.<br>3. Admin chọn loại báo cáo cần xem (doanh thu, hội viên, điểm danh, gói tập, huấn luyện viên...) và thiết lập các tiêu chí lọc cần thiết (khoảng thời gian, trạng thái...).<br>4. Admin xác nhận yêu cầu xem báo cáo.<br>5. Hệ thống truy xuất dữ liệu tương ứng với loại báo cáo và các tiêu chí lọc đã chọn.<br>6. Hệ thống tổng hợp dữ liệu và hiển thị kết quả thống kê dưới dạng bảng và/hoặc biểu đồ.<br>7. Use Case kết thúc. |
| **Dòng sự kiện phụ** | **5.1. Không có dữ liệu phù hợp:**<br>&nbsp;&nbsp;&nbsp;&nbsp;5.1.1. Hệ thống không tìm thấy dữ liệu phù hợp với các tiêu chí đã chọn.<br>&nbsp;&nbsp;&nbsp;&nbsp;5.1.2. Hệ thống hiển thị thông báo: "Không có dữ liệu phù hợp."<br>&nbsp;&nbsp;&nbsp;&nbsp;5.1.3. Quay lại bước 2 để Admin thay đổi tiêu chí tra cứu. |
| **Tiền điều kiện** | - Admin đã đăng nhập thành công vào hệ thống.<br>- Admin có quyền truy cập chức năng báo cáo và thống kê. |
| **Hậu điều kiện** | - Báo cáo được hiển thị theo tiêu chí đã chọn.<br>- Dữ liệu thống kê được trình bày dưới dạng bảng hoặc biểu đồ. |
